# Project: Simple User Directory App

```text
Create a simple React.js application to practice Hooks, form handling, API calling, state management, and React Router.
```


## Technology
- React.js
- Vite
- React Router DOM
- CSS
---


## Task 1: Project Setup
- Create a React project using Vite.
- Organize your code into components and pages folders.
---


## Task 2: Home Page
### Create a homepage with:
- A Navbar containing Home, Users, and About links.
- A welcome message.
- A button to change the page background color using useState.
---


## Task 3: useRef Practice
### Create an input field and a button.
- When the button is clicked, display the input's value using useRef.
- Use useRef to focus the input field when another button is clicked.
---


## Task 4: Form Handling
### Create a simple user form with these fields:
- Name
- Email
- Age
---


## Requirements:
- Handle the form using useState.
- Display the submitted information on the page.
- Add a reset button to clear the form.

## Task 5: Object and Array State
- Create an object containing a user's name and email.
- Add a button to update the user's name using the spread operator.
- Create an array of three skills.
- Add a new skill to the array without directly modifying the original array.
---


## Task 6: API Calling
### Create a Users page and fetch user data from this API:
```URL
https://jsonplaceholder.typicode.com/users
```
---


## Requirements:
- Use useEffect to fetch data when the page loads.
- Use async/await or Promises for the API call.
- Display each user's name and email.
- Show a loading message while fetching data.
---


## Task 7: React Router DOM
### Create three pages:
- Home
- Users
- About
---


## Requirements:
- Configure routes using BrowserRouter.
- Use Link or NavLink for navigation.
- Create a user details page using a dynamic route such as /users/:id.
- Display the selected user's ID on the details page.
---


## Task 8: Basic Styling
- Make the navbar and pages look clean.
- Use CSS to style the form, buttons, and user list.
- Make the application responsive.
---
