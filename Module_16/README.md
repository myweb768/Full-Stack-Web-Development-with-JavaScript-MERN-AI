# Objective
**Practice basic MongoDB queries using MongoDB Compass or MongoDB Atlas. Complete the following tasks using a collection named students.**

**Sample Document:**
Insert at least 5 student documents with the following fields:

* name
* age
* department
* cgpa

Example:
```json
{

  "name": "Rahim",

  "age": 22,

  "department": "CSE",

  "cgpa": 3.75

}
```


## Task 1: Insert Queries

* Insert one student document.
* Insert multiple student documents.

## Task 2: Find Queries

**Write queries to:**
* Show all students.
* Show only one student by name.
* Show only name and department (Projection).

## Task 3: Filter Queries

**Write queries to:**
* Find students whose age is greater than 20.
* Find students whose department is CSE.
* Find students whose CGPA is greater than or equal to 3.50.

## Task 4: Sort & Limit

* Sort students by CGPA (Highest First).
* Show only the first 3 students.

## Task 5: Update Queries

* Update one student's department.
* Increase one student's CGPA.

## Task 6: Delete Queries

* Delete one student by name.

## Task 7: Practice Commands

Write queries to:

* Count the total number of students.
* Show all unique departments using distinct().
