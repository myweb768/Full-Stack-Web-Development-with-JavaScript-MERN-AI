# **Assignment: Create a Simple Counter App**

**Objective: Practice React useState and event handling.**

Task:

Create a simple Counter App with the following features:

- Show a number starting from 0.
- Add an Increment (+) button to increase the number by 1.
- Add a Decrement (-) button to decrease the number by 1.
- Add a Reset button to set the number back to 0.

## Requirements:

- Use React JS.
- Use the useState hook.
- Use onClick to handle button clicks.
- Make the UI simple and clean.

Expected Output:
```
Count: 0

[ - ] [ Reset ] [ + ]
```
