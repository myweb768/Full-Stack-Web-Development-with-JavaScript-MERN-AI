# <center>Module 11 Assignement</center>
## MERN 16 || M-11 || Assignment 

Build a basic Node.js application to understand Node.js modules, file handling, HTTP server, events, and package management.

###  <div style = "color: #2e86de">  Part 1: Theory Questions</div>
Answer the following questions in your own words.

## <div style = "color: #2bcbba">Node.js Basics</div>
* What is Node.js?

* What is the difference between Single-threaded and Multi-threaded architecture?

* What is the difference between Synchronous and Asynchronous operations?

* What is the difference between Blocking and Non-blocking operations?

## <div style = "color: #2bcbba">Modules</div>
* What is a Module in Node.js?

* What is the purpose of module.exports?

* What is the purpose of require()?

## <div style = "color: #2bcbba">NPM</div>
* What is NPM?

* What information is stored inside the package.json file?

## <div style = "color: #2bcbba">Core Modules</div>
* What is the purpose of the following Node.js modules?
* **HTTP Module**
* **URL Module**
* **File System (fs) Module**
* **Path Module**
* **Events Module**

### <div style = "color: #2e86de">Part 2: Practical Task</div>
## <div style = "color: #2bcbba">Task 1: Project Setup</div>
* Create a new Node.js project.
* Initialize the project using NPM.
* Verify that the package.json file is created.

## <div style = "color: #2bcbba">Task 2: Create Your First Module</div>
* Create a file named math.js.
* Export two functions:
* add(a, b)
* subtract(a, b)
* Import the module into index.js.
* Display the result in the terminal.

## <div style = "color: #2bcbba">Task 3: Create an HTTP Server</div>
Create a simple HTTP server using the http module.
Requirements:

* Run the server on Port 5000.
* When users visit /, display:
* Welcome to My Node.js Server

* When users visit /about, display:
  This is the About Page
